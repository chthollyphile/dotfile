# Folia Lyrics for Omarchy

English · [简体中文](README_zh-CN.md)

A Quickshell status-bar lyrics plugin for Omarchy. It combines a Folia v1-compatible lyrics API with MPRIS playback position to render word-synced lyrics, falling back to the media title when lyrics are unavailable.

## Features

- Word-synced lyrics, translation fallback, global offsets, and line-gap handling
- MPRIS title fallback, MPRIS-only mode, and click-to-play/pause
- Long-text scrolling, paused-state styling, and a lightweight current-word glow

See the [full English guide](docs/guide.en.md) for installation, configuration, and development instructions.
